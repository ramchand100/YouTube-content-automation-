# Visual System

This file governs visual decisions for the channel: palette, typography,
motion graphics, and footage assembly.

---

## Colour palette

| Role | Hex | Use |
|------|-----|-----|
| Background | `#F8F9FA` | Page and card background |
| Primary text | `#1A1A1A` | Body copy, headlines |
| Secondary text | `#555555` | Captions, labels, sub-text |
| Green accent | `#1EB53A` | Growth, viable option, positive path |
| Red accent | `#D32F2F` | Cost gap, risk, decline, circular debt |
| Card background | `#FFFFFF` | Cards and callout boxes (with subtle shadow) |
| Divider / border | `#E0E0E0` | Horizontal rules, borders |

Do not use palette colours for decorative purposes. Each colour carries meaning.

---

## Typography

| Role | Typeface |
|------|----------|
| Body copy, captions, definitions | Inter |
| Numbers, titles, emphasis | Archivo Black |

## Graphics tool policy

**CapCut is the default and primary tool for editing, graphics, text, and
animation.** The channel's editor works exclusively in CapCut and has no prior
editing experience — every storyboard cue must describe something buildable
with CapCut's built-in layers, shapes, and one-tap animation presets (fade,
slide, zoom in/out). Never hand-keyframed, never a multi-element animated
build.

**Source-screenshot cards are the default graphic technique.** For any
on-screen figure traceable to a real document — an uploaded PDF, an official
webpage, a news article — screenshot the actual source (crop tight, add a
highlight box over the key figure, caption "Source: [Institution], [Date]")
instead of building a custom chart. This needs no design work and is more
credible than a recreation. Use a plain Archivo Black + Inter text/number
card only when no source document exists to screenshot.

**Canva** is used for thumbnails, social assets, and building a static
text/number card when CapCut's own tools aren't enough. Canva's "Animate"
button can add one simple preset animation before export.

Never build a custom animated chart (bar/donut/animated timeline) — beyond
this editor's skill level. Use two simple side-by-side cards instead.

Footage cues live in storyboards only. They never appear inside the script.
Footage should be the dominant visual layer — most of a storyboard's runtime
should be B-roll the editor can drop onto the timeline, with graphics
reserved for the few moments that genuinely need a number on screen.

**Remotion** (`remotion/`) is a legacy pipeline requiring rendered React code.
Not part of the default workflow — only use it if the user explicitly asks
for a Remotion-rendered graphic on a specific episode.

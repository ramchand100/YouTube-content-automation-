# Storyboard template — superseded

This file predates the channel's move to a flexible Part-N script structure
and a CapCut-first visual pipeline, and was left un-migrated (still built
around Remotion composition names and a fixed section count) while the real
templates moved on. Rather than maintain two parallel copies that can drift
out of sync again, this file now points to the current ones instead of
duplicating their content:

- **Storyboard structure and format:** `storyboards/TEMPLATE.md` — the
  flexible Part-N, cue-level template every real episode storyboard actually
  uses.
- **Storyboard rules:** `.claude/rules/storyboards.md`.
- **Visual system (CapCut-first graphics, palette, source-screenshot
  cards):** `.claude/rules/visual-system.md`.

Use those three files when building a storyboard. Do not resurrect a
Remotion-composition-based template here.

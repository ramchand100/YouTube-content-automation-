# Topic Ideas Backlog

Every topic idea proposed in a brainstorming pass, so a session never repeats
one and the user can browse the full list without scrolling chat history.

**Before proposing new topic ideas, read this file first** — check both
"Produced" and "Proposed / unclaimed" so you don't suggest something already
covered or already on the list. When you propose a fresh batch, append it
here (don't just answer in chat and let it evaporate). When one gets picked,
move it to "Parked — angle work started" or mark it produced once an episode
exists.

**Known gap, flagged 2026-08-29 — correct for this going forward.** Every
idea in Batches 1-3 is framed as a failure, crisis, cartel, gap, or
collapse. None asked "what actually worked, and why." CLAUDE.md's own
"brands" pillar (`tools/topic_generator.py`) is explicitly about success
mechanics (distribution moats, export wins) and had never been used. A
channel that only ever finds dysfunction reads as having an agenda, which
works against the sourcing-rigor credibility CLAUDE.md cares about. Batch 4
below corrects this — when brainstorming further, keep including genuine
success/benefit angles, not just critical ones. Also flagged: regional
skew (almost everything is Punjab/Sindh/Karachi-centric — nothing from
Balochistan, KP, or Gilgit-Baltistan until Batch 4).
